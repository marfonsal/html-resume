# html-resume

# 🧱 Week 1 – CSS Redimido: Semantic HTML Multipage Site

This project was built as part of my structured learning campaign to master front-end development. It represents the completion of Week 1 of my bootcamp, focused on semantic HTML and multi-page structure.

## 📄 Project Overview

A simple, clean multipage website built using semantic HTML5. It includes:

- A homepage (`index.html`)
- An "About Me" page
- A "Contact" page with a basic form

Each page is linked through a functional navigation bar and follows accessibility and semantic best practices.

## 🛠️ Technologies Used

- HTML5
- Basic CSS (to be added in future chapters)
- Git & GitHub for version control and deployment
